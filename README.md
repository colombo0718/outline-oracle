# Outline Oracle（OO）

LeafLune 宇宙的**事項與檔案管家**。

對位 [expense-echo](https://github.com/colombo0718/expense-echo)（EE、管錢的依依）、OO 是管事的凌凌——

> **EE 回響過去花了什麼、OO 預言未來該做什麼。**

---

## Agent 三身一名

| Tier | 名字 | 職稱 | 服務對象 |
|------|------|------|---------|
| Free | **伶伶** | 藏經閣小書童 | 個人、童趣陪讀 |
| Paid | **凌凌** | 藏經閣才子 | 家庭、雅致書箋 |
| Enterprise | **翎翎** | 藏經閣翰林 | 企業、嚴密典藏 |

## 功能

- **待辦提醒** — 跟凌凌說一句、他幫你記著、到期自動催
- **檔案管理** — 把文件丟給凌凌、他歸檔、要找時叫得出來
- **專案管理** — 一個目標、多個待辦、多份檔案、凌凌跟著進度
